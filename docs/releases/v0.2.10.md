Install **Still-Motion-Studio-Setup-0.2.10.exe** on Windows x64, or use **Updates** in an existing installation.

- **Restored scenes open reliably:** fixed a renderer race that could leave the editor blank when loading a character with a different skeleton.
- **Guided physics review:** play Before and After together, jump to the largest reported root-position changes, and choose **Keep correction** or **Use original motion**.
- Restoring the original preserves authored keyframe IDs and timing. One Undo brings back the correction and its comparison.
- Detailed engine measurements remain available in a collapsed technical section. A completed correction is identified separately from a result whose physical realism still needs review.
- Includes the synchronized side-by-side viewport, permanent scene library, bulk keyframe deletion, and camera-preserving Undo/Redo from previous releases.

This update improves startup and review controls; it does not add a new whole-body physics solver or certify a correction as physically realistic. The standalone humanoid AI model remains excluded by its motion-quality gate.

The installer is unsigned and Windows x64 only. The `.blockmap` and `latest.yml` assets support automatic updates. `SHA256SUMS.txt` and `release-source.json` identify the shipped build. No user scene or GitHub token is included.
