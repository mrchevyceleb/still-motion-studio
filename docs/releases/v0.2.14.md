Install **Still-Motion-Studio-Setup-0.2.14.exe** on Windows x64, or choose **Updates** in an existing installation.

- **Fast updates:** Still's Python, Blender and model runtime now lives in its own folder outside the install folder (`%LOCALAPPDATA%\Still Motion Studio\runtime`). Updates that don't change the runtime download a small app-only installer and no longer uninstall and re-extract about 30,000 runtime files, so Still closes and reopens in under a minute instead of many minutes. Python's compiled cache also survives updates, so the first launch after an update starts warm.
- **This update is the last slow one:** moving from 0.2.13 to 0.2.14 still runs 0.2.13's own uninstaller over the old runtime once. Updates after 0.2.14 take the fast path.
- **Downloads that stall now recover:** if an update download stops making progress for two minutes, Still cancels it and retries by itself, up to three times, then shows a clear error with the Check for updates button available again.

Includes everything from 0.2.13: animation-only export onto an existing Unreal character's skeleton, face shapes as Unreal morph curves, Extract root motion by default, and saving packages straight into a folder.

The installers are unsigned and Windows x64 only. `Still-Motion-Studio-Setup-0.2.14.exe` is the full installer; `Still-Motion-Studio-Update-0.2.14.exe` is the app-only update. Matching `.blockmap`, `latest.yml`, `SHA256SUMS.txt`, and `release-source.json` assets support verified automatic updates. No user scenes or GitHub credentials are included.
