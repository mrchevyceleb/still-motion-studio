Install **Still-Motion-Studio-Setup-0.2.9.exe** on Windows x64, or use **Updates** in an existing installation.

- **Side-by-side physics comparison:** Before appears on the left and After on the right, with shared playback, scrubbing, orbit, pan, and zoom. Saved physics comparisons open in this view automatically.
- Choose **Before**, **Side by side**, or **After** above the character. The original is a read-only preview; edits on the right and exports use the corrected motion.
- Comparisons saved with your scenes continue working. Older physics passes without a saved original need to be run again to enable comparison.

The installer is unsigned and Windows x64 only. The standalone humanoid model remains excluded by its motion-quality gate.

The `.blockmap` and `latest.yml` assets support automatic updates. `SHA256SUMS.txt` and `release-source.json` identify the shipped build. No user scene or GitHub token is included.
