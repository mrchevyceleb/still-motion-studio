Install **Still-Motion-Studio-Setup-0.2.22.exe**, or choose **Updates** in Still. The smaller **Still-Motion-Studio-Update-0.2.22.exe** is for installations with the matching offline runtime.

- Add editable creature rigs for hydra heads and jaws, serpents, and tentacles. Fit 1–8 chains without requiring legs, adjust joint placement, then bind the mesh.
- Import FBX, GLB/glTF and BVH animation onto the current character. Match an existing rig or map joints to transfer rotations and optional root/hip motion while preserving target proportions.
- Find animation and character sources through Mesh2Motion, Quaternius, ActorCore, Fab and Mixamo links in the import dialogs.
- Preserve existing skeletons, skin weights, saved scenes, and all features shipped in 0.2.21.

Creature fitting is an editable geometric starting point; unusual meshes can need manual placement and weight refinement. Human and quadruped AI/physics engines remain limited to their supported anatomy. This release does not bundle a neural auto-rigging engine or guarantee compatibility between unrelated skeletons.
