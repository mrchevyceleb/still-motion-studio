# Still Motion Studio 0.2.22

Public-source preparation based on the shipped 0.2.21 editor.

- MIT license for the project's original code, contribution and security guidance, issue templates, and Windows/Linux CI.
- Public GitHub updates without an account, access token or bundled GitHub CLI. Existing scene-saving and busy-job restart checks remain in place.
- Neutral editor surfaces with blue copy/selection controls, violet motion tools and amber whole-animation edits, making dense menus easier to scan in both themes.
- Fresh-clone development instructions. Desktop builds can omit unavailable learned models and construct their physics configuration without developer-local manifests.
- Generated JavaScript dependency notices and a release requirement for the matching Blender source archive.

This source prepares the next desktop release; an installer is available only when attached to its published release. Existing 0.2.21 and earlier installers use the previous private-repository update flow. Use a new full **Setup** installer to move to the public runtime.

No standalone humanoid model or CondMDI weights are included. See [third-party notices](../../THIRD_PARTY_NOTICES.md) for dependency and asset terms.
