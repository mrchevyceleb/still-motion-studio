# Still Motion Studio 0.2.25

The first release built and published automatically from `main`. From now on every change merged to `main` ships as a new release.

- Includes everything from 0.2.24: the offline CC0 Motion Library, My Motions, joint-map reuse and optional Meshy motion.
- Agent tools can delete files they staged in their own session once no job or open scene uses them (`DELETE /files/:id`).
- Three.js 0.186.1 and updated development tools.
- Open-source launch documentation: download, quick start, building from source and how releases work.

The Windows x64 installers are unsigned. Verify downloads with `SHA256SUMS.txt`. The runtime is now assembled on GitHub Actions, so updating from 0.2.24 downloads the full Setup once; later updates use the small Update installer until Python, Blender or a model changes. Bundled motion sources and CC0 terms are recorded in `public/motions/NOTICE.txt`.
