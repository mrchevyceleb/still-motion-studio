Install **Still-Motion-Studio-Setup-0.2.18.exe**, or choose **Updates** in Still.

- **S** toggles between Select mode and regular editing. **Esc** or **V** returns to regular mode and clears the selection.
- **R** toggles Ripple. **M** opens the selected keyframe’s move-to-time control. **W / E** select the move / rotate joint tools and leave Select mode.
- **Home / End** jump to the clip boundaries. **Ctrl A** enters Select mode and selects all keyframes. **Ctrl Y** joins **Ctrl Shift Z** as Redo.
- Press **?** or **F1**, or click **Shortcuts**, for a dedicated shortcut sheet. Mode buttons show their shortcuts.
- Shortcuts respect text fields, dialogs and active operations. Holding a mode key does not repeatedly flip modes; IME composition and native slider keys are preserved.

Includes saved characters and scenes, keyframe copy/paste, exact-frame moving, and clip trimming from 0.2.17. Full and app-only Windows x64 installers include verified update metadata.
