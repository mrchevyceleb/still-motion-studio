Install **Still-Motion-Studio-Setup-0.2.13.exe** on Windows x64, or choose **Updates** in an existing installation.

- **Animate a character already in Unreal:** in the Unreal export, choose **My existing Unreal character (animation only)**, enter its Skeleton asset path, and pick the character FBX you imported into Unreal. Still exports an animation-only FBX with that skeleton's exact bone names, hierarchy and rest pose, so it imports straight onto the existing Skeleton with no retarget. Extra bones such as fists or props follow their parent at rest.
- **Gameplay root motion on game skeletons:** Extract is now the default for travelling moves. On an Unreal-exported character it keys bone 0, the bone Unreal reads root motion from, while the body keeps its height, bobbing, pitch and roll. Original movement remains one click away.
- **Face shapes:** characters with morph targets show **Face & shapes** sliders. Weights key with the pose, play in the viewport, save with the scene, and export as Unreal morph curves named exactly like the shapes. On an existing character, shapes with matching names are exported and any others are listed in a warning.
- **Save into a folder:** enable **Save into a folder** to extract the finished package into a named subfolder. Existing files are never overwritten; a failed save downloads the ZIP instead.

Includes hand and finger rigging, clip tools, bulk keyframe corrections, the scene library, and guided physics comparisons from earlier releases. The standalone humanoid AI model remains excluded by its motion-quality gate.

The installer is unsigned and Windows x64 only. Matching `.blockmap`, `latest.yml`, `SHA256SUMS.txt`, and `release-source.json` assets support verified automatic updates. No user scenes or GitHub credentials are included.
