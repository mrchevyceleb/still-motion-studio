Install **Still-Motion-Studio-Setup-0.2.16.exe** on Windows x64, or choose **Updates** in an existing installation.

- **Swap look:** under **Your character**, choose **Swap look** and select an FBX or GLB rigged on the same skeleton. The new mesh, materials, textures and props replace the old surface. Bones, rest pose and every key stay exactly as they were.
- **Exact when the rig matches:** when the new look shares the old one's bind pose (the same rig re-dressed in Blender), Still reuses the original binding, so it deforms exactly as before. A different bind pose is re-posed by the look's own skin weights, with a warning to check joints.
- **Props stay on the rig:** extra joints in the new look follow their nearest matching bone; no bones are added. Unreal exports keep the same skeleton, so motion exported earlier still fits.
- **Agent:** `character.swapLook` does the same from scripts and opens the result as a new scene.

Bones are matched by name, ignoring Mixamo namespaces. Looks with different proportions are rejected.

Includes Import animation from 0.2.15 and the app-only update support and existing-skeleton Unreal export from 0.2.14. The installers are unsigned and Windows x64 only. `Still-Motion-Studio-Setup-0.2.16.exe` is the full installer; `Still-Motion-Studio-Update-0.2.16.exe` is the app-only update. Matching blockmaps, `latest.yml`, hashes, and source identity support verified automatic updates. No user scenes or GitHub credentials are included.
