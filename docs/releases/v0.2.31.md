CEG: Users can turn their authored humanoid poses into convincing continuous motion locally, preview it on their own character, and reliably edit, save and export the result without losing their original work.

# Still Motion Studio 0.2.31

- Generate continuous humanoid motion locally with NVIDIA MotionBricks. The pinned model and CPU runtime are included in the full installer, with their licenses; generation needs no cloud account or CUDA setup.
- Keep the original rig and exact authored key poses. Recognized Mixamo, Still and Unreal humanoid rigs support clips up to 20 seconds; unusual proportions and foot contacts should be reviewed.
- Dense imported clips retain a separate original scene before six poses are extracted. Editing, Undo, cancellation and portable source guides preserve the work needed to revise a take.
- Improve phone header layout, original-scene thumbnails, camera framing and save handling after clip edits.

This release changes the bundled runtime, so existing installations receive the full Setup once. Later app-only updates can reuse it.
