# Still Motion Studio 0.2.23

Install **Still-Motion-Studio-Setup-0.2.23.exe** for the updated public runtime. Existing 0.2.22 and earlier builds may still show the private GitHub sign-in flow; installing the full Setup preserves your local scenes and preferences.

- Neutral slate panels and viewport, blue selection/copy tools, violet motion controls and amber whole-animation edits make dense menus easier to distinguish in both themes.
- Public updates without GitHub sign-in, an access token or bundled GitHub CLI.
- Remove Cascadeur AI and AutoPhysics, automatic installation detection, bridge requests and native cleanup jobs. Old manifests and recovery journals are ignored. Saved motion stays usable; MuJoCo physics and animal motion remain available.
- Preserve 0.2.22 creature rigs, BVH import, joint mapping and curated animation-library links.
- MIT license for original code, contribution/security guidance, generated dependency notices and matching Blender source alongside the Windows installers.

No standalone humanoid model or CondMDI weights are included. The Windows x64 installer is unsigned. See [third-party notices](../../THIRD_PARTY_NOTICES.md) for dependency and asset terms.
