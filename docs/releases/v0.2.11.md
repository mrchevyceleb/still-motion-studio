Install **Still-Motion-Studio-Setup-0.2.11.exe** on Windows x64, or choose **Updates** in an existing installation.

- **Correct several poses together:** open timeline **Position & property tools**, move one pose, select keyframes, and apply the same correction. Choose X, Y (height), and Z independently to preserve the remaining movement.
- **Paste one property:** copy the current model position or selected joint rotation, choose **Exact value**, and apply only the checked axes to selected poses.
- **Move the entire animation:** offset authored poses and generated frames together without rebuilding the take. Imported rigs retain their normalization, and independent skeleton roots move together.
- The source pose is kept as corrected. Each bulk operation is one Undo, and all changes save in the scene library and travel with `.still`, GLB, and Unreal exports.
- Editing authored poses clears an older generated take. Whole-animation offsets retain AI provenance; physics comparisons move with the take and stale measurements are flagged for a fresh physics check.
- Focusing a property control pauses playback. Invalid imported transforms show an error inside the tools while the editor remains available.

Includes the scene library, guided physics comparisons, and stable-camera Undo/Redo from earlier releases. The standalone humanoid AI model remains excluded by its motion-quality gate.

The installer is unsigned and Windows x64 only. Matching `.blockmap`, `latest.yml`, `SHA256SUMS.txt`, and `release-source.json` assets support verified automatic updates. No user scenes or GitHub credentials are included.
