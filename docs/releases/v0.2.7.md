Install **Still-Motion-Studio-Setup-0.2.7.exe** on Windows x64, or use **Updates** in an existing installation.

- Timeline drags no longer open the file-import overlay. Real file drops still import characters and projects.
- Turn on **Ripple** or hold **Shift** while dragging the first diamond after a gap. That moment and every later pose move together, shortening or extending the clip without changing their spacing or poses.
- With a diamond focused, **Alt Shift ← / →** ripples one frame at a time. With Ripple on, **Alt ← / →** does the same.
- The ruler, playhead and clip length update during the drag. **Escape** cancels; one **Ctrl Z** restores the complete edit, including any generated take.
- Ripple timing respects the preceding pose, the start of the timeline and the 10-minute duration limit.

The installer remains unsigned and Windows x64 only. The standalone humanoid model remains excluded by its motion-quality gate; curve interpolation and the separately installed licensed Cascadeur adapter remain available.

The `.blockmap` and `latest.yml` assets support automatic updates. `SHA256SUMS.txt` and `release-source.json` identify the shipped build. No user project or GitHub token is included.
