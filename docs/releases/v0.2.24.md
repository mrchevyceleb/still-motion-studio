# Still Motion Studio 0.2.24

- Browse and search 310 offline CC0 clips for human, quadruped and creature rigs. Preview a motion on the current character, then Apply or Append it with one-step Undo.
- Save downloaded FBX, GLB and BVH clips in My Motions for use across scenes. Mixamo opens in your browser so you can add its downloaded file.
- Review and reuse joint maps when skeletons differ. Existing scene files remain compatible.
- Optionally connect your own Meshy account for preset or generated motion. Still shows the published credit cost before a paid task and stores the desktop API key with Windows secure storage.

The Windows x64 installers remain unsigned. Bundled motion sources, versions, hashes and CC0 terms are recorded in `public/motions/NOTICE.txt` and `public/motions/catalog.json`.
