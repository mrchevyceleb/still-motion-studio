Install **Still-Motion-Studio-Setup-0.2.6.exe** on Windows x64, or use **Updates** in an existing installation.

- Unreal exports now normalize Mixamo joint names consistently: `mixamorig:Hips` and `mixamorigHips` become `Hips`, including animation tracks and skin weights.
- **My original skeleton → Existing Unreal skeleton** now accepts a matching Skeleton or SkeletalMesh asset path. The import helper imports the animation directly onto that skeleton and skips the duplicate character import.
- Incompatible bone names or roots are rejected with a clear message. Different rigs still need retargeting; renaming cannot fix a different skeleton hierarchy.
- Export success messages and the packaged import guide now explain the selected import route correctly.

Direct imports onto matching Skeleton and SkeletalMesh assets, normal new-character imports, and incompatible-target rejection were checked in Unreal Engine 5.8.2. All 33 tracks in the test walk were retained, with preserved duration and less than 0.001 cm maximum sampled joint-position error.

The installer remains unsigned and Windows x64 only. The standalone humanoid model remains excluded by its motion-quality gate; curve interpolation and the separately installed licensed Cascadeur adapter remain available.

The `.blockmap` and `latest.yml` assets support automatic updates. `SHA256SUMS.txt` and `release-source.json` identify the shipped build. No user project or GitHub token is included.
