Install **Still-Motion-Studio-Setup-0.2.8.exe** on Windows x64, or use **Updates** in an existing installation.

- **Permanent scene library:** open **Scenes** beside the project name to search, reopen, rename, duplicate, or delete saved scenes. Each scene autosaves independently on this device. Your current scene joins the library automatically; recent backups remain available for recovery. Export a `.still` file for a portable copy.
- Switching scenes saves the outgoing work first. Conflicting edits from another window are saved separately, and healthy library scenes remain accessible if the current recovery copy cannot load.
- **Delete multiple keyframes:** turn on **Select**, drag across timeline diamonds, then choose **Delete selected**. Ctrl-click adds or removes individual poses. Escape clears the selection, and one Undo restores the whole deletion. At least two poses remain required.
- **Physics Before/After:** switch between the original and corrected motion at the same time and camera position. The physics report shows available floor/contact and force measurements, pose displacement, and review warnings. Comparisons persist in saved scenes and `.still` files; older passes need to be rerun to capture a Before preview.
- Physics correction preserves all authored keyframe IDs and times instead of silently reducing dense clips to six keys. An applied result that still needs review is labeled accordingly.
- Undo and Redo of pose edits preserve the viewport camera's orbit, pan, and zoom.

The standalone humanoid model remains excluded by its motion-quality gate; curve interpolation and separately installed licensed Cascadeur adapters remain available. The installer is unsigned and Windows x64 only.

The `.blockmap` and `latest.yml` assets support automatic updates. `SHA256SUMS.txt` and `release-source.json` identify the shipped build. No user scene or GitHub token is included.
